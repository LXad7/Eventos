Alínea a)Menu de opções + estrutura do menu no main()

Elaborar uma função que apresente num menu de opções as funcionalidades (Novo funcionário; Listar; Percentagem com vencimento > 1000€; Alterar vencimento; Escrever ficheiro binário; Ler ficheiro binário). O menu deverá também apresentar a quantidade de funcionários, a média dos vencimentos e a quantidade de admitidos desde novembro de 2020. Implementar a estrutura do menu na função main().

Como resolver
  • A função menu() só mostra e lê a opção; os valores (quantidade, média, admitidos) chegam-lhe por parâmetro.
  • No main(), dentro do do … while, calculam-se a média (alínea g) e os admitidos (alínea i) antes de chamar o menu, para estarem sempre atualizados.
  • toupper() (de <ctype.h>) aceita a opção em minúscula ou maiúscula; limpaBufferStdin() tira o Enter que ficou no buffer.
  • O switch usa letras; o ciclo termina com 'S'. Lembra-te do break em cada case.
  • Repara que quantFunc = acrescentaFuncionario(...) e quantFunc = leFicheiroBinario(...): estas funções devolvem a nova quantidade.
/* a) Estrutura do menu na funcao main() */
int main(void)
{
    tipoFuncionario funcionarios[MAX_FUNCIONARIOS];   /* c) estrutura de dados */
    int quantFunc = 0;
    int quantAdmitidos;
    float media;
    char opcao;

    do
    {
        media = mediaVencimentos(funcionarios, quantFunc);
        quantAdmitidos = admitidosDesdeNov2020(funcionarios, quantFunc);
        opcao = menu(quantFunc, media, quantAdmitidos);

        switch (opcao)
        {
        case 'N':
            quantFunc = acrescentaFuncionario(funcionarios, quantFunc);
            break;
        case 'L':
            mostraFuncionarios(funcionarios, quantFunc);
            break;
        case 'P':
            percentagemVencimentoSuperior(funcionarios, quantFunc);
            break;
        case 'A':
            alteraVencimento(funcionarios, quantFunc);
            break;
        case 'E':
            gravaFicheiroBinario(funcionarios, quantFunc);
            break;
        case 'R':
            quantFunc = leFicheiroBinario(funcionarios);
            break;
        case 'S':
            printf("\nFim do programa\n");
            break;
        default:
            printf("\nOpcao invalida\n");
        }
    }
    while (opcao != 'S');

    return 0;
}
/* a) Menu de opcoes */

{
    char op;

    printf("\n\n************** Gestao de Funcionarios **************\n");

Alínea d)Novo funcionário com número único

Elaborar uma função que armazene na estrutura os dados de um novo funcionário, que deverá ter um número único (não repetido).

Como resolver
  1. Se o vetor está cheio (quantFunc == MAX_FUNCIONARIOS) avisa e não faz nada.
  2. Lê os dados com lerDadosFuncionario() (usa lerInteiro, lerString, lerFloat, lerData).
  3. procuraFuncionario() devolve a posição ou -1. Só acrescenta se for -1.
  4. Acrescenta na posição quantFunc e incrementa. Devolve a nova quantidade (passagem por valor!).
/* Obtem os dados de um funcionario */
tipoFuncionario lerDadosFuncionario(void)
{
    tipoFuncionario func;

    printf("Numero do funcionario (1 a 9999): ");
    func.numero = lerInteiro(1, 9999);

    printf("Nome: ");
    lerString(func.nome, MAX_NOME);

    printf("Vencimento mensal (euros): ");
    func.vencimento = lerFloat(0, 100000);

    printf("Data de admissao:");
    func.dataAdmissao = lerData();

    return func;
}
/* Devolve a posicao do funcionario com esse numero, ou -1 se nao existir */
int procuraFuncionario(tipoFuncionario vetor[MAX_FUNCIONARIOS], int quantFunc, int numero)
{
    int i, pos = -1;

    for (i = 0; i < quantFunc; i++)
    {
        if (vetor[i].numero == numero)
        {
            pos = i;
            i = quantFunc;      /* termina a pesquisa */
        }
    }
    return pos;
}
/* d) Acrescenta um funcionario com numero unico; devolve a nova quantidade */
int acrescentaFuncionario(tipoFuncionario vetor[MAX_FUNCIONARIOS], int quantFunc)
{
    tipoFuncionario func;

    if (quantFunc == MAX_FUNCIONARIOS)
    {
        printf("\nImpossivel acrescentar: limite de %d funcionarios atingido\n", MAX_FUNCIONARIOS);
    }
    else
    {
        func = lerDadosFuncionario();
        if (procuraFuncionario(vetor, quantFunc, func.numero) != -1)
        {
            printf("\nJa existe um funcionario com o numero %d - nao foi acrescentado\n", func.numero);
        }
        else
        {
            vetor[quantFunc] = func;
            quantFunc++;
        }
    }
    return quantFunc;
}
Alínea e)Mostrar os dados de um funcionário

Elaborar uma função que apresente no monitor os dados de um funcionário.

Como resolver

Recebe um funcionário (por valor, só lê). %-25s alinha o nome à esquerda em 25 colunas; %02d mostra 03 em vez de 3 nas datas; %.2f dá 2 casas decimais.

/* e) Mostra os dados de um funcionario */
void mostraFuncionario(tipoFuncionario func)
{
    printf("\n %4d  %-25s %10.2f   %02d/%02d/%04d", func.numero, func.nome, func.vencimento,
           func.dataAdmissao.dia, func.dataAdmissao.mes, func.dataAdmissao.ano);
}
Alínea f)Mostrar todos os funcionários

Elaborar uma função que apresente no monitor os dados de todos os funcionários.

Como resolver

Ciclo de 0 até quantFunc (não até 50!) chamando a função da alínea e). Trata o caso de não haver funcionários.

/* f) Mostra os dados de todos os funcionarios */
void mostraFuncionarios(tipoFuncionario vetor[MAX_FUNCIONARIOS], int quantFunc)
{
    int i;

    if (quantFunc == 0)
    {
        printf("\nNao existem funcionarios registados\n");
    }
    else
    {
        printf("\n Num.  Nome                      Vencimento   Admissao");
        for (i = 0; i < quantFunc; i++)
        {
            mostraFuncionario(vetor[i]);
        }
        printf("\n");
    }
}
Alínea g)Média dos vencimentos

Elaborar uma função que calcule, e devolva, a média dos vencimentos mensais dos funcionários.

Como resolver

Soma tudo e divide por quantFunc, mas só se quantFunc > 0 (divisão por zero!). Devolve float; quem mostra é o menu.

/* g) Calcula e devolve a media dos vencimentos mensais */
float mediaVencimentos(tipoFuncionario vetor[MAX_FUNCIONARIOS], int quantFunc)
{
    int i;
    float soma = 0, media = 0;

    for (i = 0; i < quantFunc; i++)
    {
        soma += vetor[i].vencimento;
    }
    if (quantFunc > 0)
    {
        media = soma / quantFunc;
    }
    return media;
}
Alínea h)Percentagem com vencimento superior a 1000€

Elaborar uma função que calcule, e apresente no monitor, a percentagem de funcionários com vencimento mensal superior a 1000€. Deverá também listar os dados desses funcionários.

Como resolver
  • “Calcule e apresente” → a função é void e faz o printf.
  • No mesmo ciclo conta e lista (reutiliza mostraFuncionario).
  • (float) conta * 100 / quantFunc: o cast evita a divisão inteira (1*100/3 daria 33 em vez de 33.33).
  • “Superior” é > (1000€ exatos não contam). %% no printf mostra o símbolo %.
/* h) Calcula e apresenta a percentagem de funcionarios com vencimento > 1000 euros
      e lista os dados desses funcionarios */
void percentagemVencimentoSuperior(tipoFuncionario vetor[MAX_FUNCIONARIOS], int quantFunc)
{
    int i, conta = 0;
    float percentagem;

    if (quantFunc == 0)
    {
        printf("\nNao existem funcionarios registados\n");
    }
    else
    {
        printf("\n Num.  Nome                      Vencimento   Admissao");
        for (i = 0; i < quantFunc; i++)
        {
            if (vetor[i].vencimento > VENCIMENTO_REF)
            {
                mostraFuncionario(vetor[i]);
                conta++;
            }
        }
        percentagem = (float) conta * 100 / quantFunc;
        printf("\n\nFuncionarios com vencimento superior a 1000 euros: %d (%.2f%%)\n", conta, percentagem);
    }
}
Alínea i)Admitidos desde novembro de 2020 + ficheiro de texto

Elaborar uma função que calcule, e devolva, a quantidade de funcionários admitidos desde novembro de 2020 (inclusive). Deverá também armazenar num ficheiro de texto os dados desses funcionários.

Como resolver
  • Condição de data: ano > 2020 ou (ano == 2020 e mes >= 11). “Inclusive” → >= 11.
  • Ficheiro de texto: fopen(..., "w"), fprintf em vez de printf, fclose.
  • Mesmo que o ficheiro não abra, a função continua a contar (o menu precisa do valor).
  • Como o menu chama esta função a cada volta, o ficheiro fica sempre atualizado.
/* i) Calcula e devolve a quantidade de funcionarios admitidos desde novembro de 2020
      (inclusive) e guarda os dados desses funcionarios num ficheiro de texto */
int admitidosDesdeNov2020(tipoFuncionario vetor[MAX_FUNCIONARIOS], int quantFunc)
{
    FILE *ficheiro;
    int i, conta = 0;
    tipoData d;

    ficheiro = fopen(FICH_TEXTO, "w");
    if (ficheiro == NULL)
    {
        printf("\nErro ao abrir o ficheiro %s\n", FICH_TEXTO);
    }
    else
    {
        fprintf(ficheiro, "Funcionarios admitidos desde novembro de 2020\n");
        fprintf(ficheiro, "Numero\tNome\tVencimento\tData de admissao\n");
    }

    for (i = 0; i < quantFunc; i++)
    {
        d = vetor[i].dataAdmissao;
        if (d.ano > 2020 || (d.ano == 2020 && d.mes >= 11))
        {
            conta++;
            if (ficheiro != NULL)
            {
                fprintf(ficheiro, "%d\t%s\t%.2f\t%02d/%02d/%04d\n", vetor[i].numero, vetor[i].nome,
                        vetor[i].vencimento, d.dia, d.mes, d.ano);
            }
        }
    }

    if (ficheiro != NULL)
    {
        fprintf(ficheiro, "Total: %d\n", conta);
        fclose(ficheiro);
    }
    return conta;
}
Alínea j)Alterar o vencimento de um funcionário

Elaborar uma função que altere o vencimento do funcionário com o número indicado pelo utilizador.

Como resolver

Pede o número, usa procuraFuncionario() (a mesma da alínea d) e, se existir, altera vetor[pos].vencimento. Como o vetor é passado por referência, a alteração fica no main() sem precisar de return.

/* j) Altera o vencimento do funcionario com o numero indicado pelo utilizador */
void alteraVencimento(tipoFuncionario vetor[MAX_FUNCIONARIOS], int quantFunc)
{
    int numero, pos;

    if (quantFunc == 0)
    {
        printf("\nNao existem funcionarios registados\n");
    }
    else
    {
        printf("Numero do funcionario: ");
        numero = lerInteiro(1, 9999);
        pos = procuraFuncionario(vetor, quantFunc, numero);
        if (pos == -1)
        {
            printf("\nNao existe nenhum funcionario com o numero %d\n", numero);
        }
        else
        {
            printf("Vencimento atual: %.2f euros\n", vetor[pos].vencimento);
            printf("Novo vencimento (euros): ");
            vetor[pos].vencimento = lerFloat(0, 100000);
        }
    }
}
Alínea k)Escrever num ficheiro binário

Elaborar uma função para escrever num ficheiro binário os dados de todos os funcionários.

Como resolver

Igual à Ficha 6: "wb" → fwrite(&quantFunc, sizeof(int), 1, f) → fwrite(vetor, sizeof(tipoFuncionario), quantFunc, f) → fclose. O valor devolvido pelo fwrite é a quantidade escrita: serve para detetar erros.

/* k) Escreve num ficheiro binario os dados de todos os funcionarios */
void gravaFicheiroBinario(tipoFuncionario vetor[MAX_FUNCIONARIOS], int quantFunc)
{
    FILE *ficheiro;
    int quant;

    ficheiro = fopen(FICH_BINARIO, "wb");
    if (ficheiro == NULL)
    {
        printf("\nErro ao abrir o ficheiro %s\n", FICH_BINARIO);
    }
    else
    {
        quant = fwrite(&quantFunc, sizeof(int), 1, ficheiro);
        if (quant != 1)
        {
            printf("\nErro ao escrever no ficheiro\n");
        }
        else
        {
            quant = fwrite(vetor, sizeof(tipoFuncionario), quantFunc, ficheiro);
            if (quant != quantFunc)
            {
                printf("\nErro ao escrever no ficheiro (%d de %d)\n", quant, quantFunc);
            }
            else
            {
                printf("\nDados de %d funcionarios gravados em %s\n", quantFunc, FICH_BINARIO);
            }
        }
        fclose(ficheiro);
    }
}
Alínea l)Ler do ficheiro binário

Elaborar uma função para obter do ficheiro binário os dados dos funcionários.

Como resolver

"rb", lê primeiro a quantidade e depois o vetor (mesma ordem da escrita). Devolve a quantidade lida (0 se houver erro). Verificar também se a quantidade lida cabe no vetor (≤ 50) evita estragar a memória com um ficheiro corrompido.

/* l) Obtem do ficheiro binario os dados dos funcionarios; devolve a quantidade lida */
int leFicheiroBinario(tipoFuncionario vetor[MAX_FUNCIONARIOS])
{
    FILE *ficheiro;
    int quantFunc = 0, quant;

    ficheiro = fopen(FICH_BINARIO, "rb");
    if (ficheiro == NULL)
    {
        printf("\nErro ao abrir o ficheiro %s\n", FICH_BINARIO);
    }
    else
    {
        quant = fread(&quantFunc, sizeof(int), 1, ficheiro);
        if (quant != 1 || quantFunc < 0 || quantFunc > MAX_FUNCIONARIOS)
        {
            printf("\nErro ao ler do ficheiro\n");
            quantFunc = 0;
        }
        else
        {
            quant = fread(vetor, sizeof(tipoFuncionario), quantFunc, ficheiro);
            if (quant != quantFunc)
            {
                printf("\nErro ao ler do ficheiro (%d de %d)\n", quant, quantFunc);
                quantFunc = 0;
            }
            else
            {
                printf("\nDados de %d funcionarios lidos de %s\n", quantFunc, FICH_BINARIO);
            }
        }
        fclose(ficheiro);
    }
    return quantFunc;
}

/************ Funcoes para leitura de dados ************/

void limpaBufferStdin(void)
{
    int lixo;

    do
    {
        lixo = getchar();
    }
    while (lixo != '\n' && lixo != EOF);
}

int lerInteiro(int min, int max)
{
    int numero = 0, controlo;

    do
    {
        controlo = scanf("%d", &numero);
        limpaBufferStdin();
    }
    while (numero < min || numero > max || controlo == 0);

    return numero;
}

float lerFloat(float min, float max)
{
    float numero = 0;
    int controlo;

    do
    {
        controlo = scanf("%f", &numero);
        limpaBufferStdin();
    }
    while (numero < min || numero > max || controlo == 0);

    return numero;
}

void lerString(char vetor[], int max)
{
    int tamanhoString;

    do
    {
        fgets(vetor, max, stdin);
        tamanhoString = strlen(vetor);
    }
    while (tamanhoString == 1);    /* repete se so foi introduzido o \n */

    if (vetor[tamanhoString - 1] != '\n')
    {
        limpaBufferStdin();
    }
    else
    {
        vetor[tamanhoString - 1] = '\0';
    }
}

tipoData lerData(void)
{
    tipoData data;
    int maxDiaMes;

    printf("\n Ano (%d a %d): ", 1950, 2026);
    data.ano = lerInteiro(1950, 2026);

    printf(" Mes (%d a %d): ", 1, 12);
    data.mes = lerInteiro(1, 12);

    switch (data.mes)
    {
    case 2:
        if ((data.ano % 400 == 0) || (data.ano % 4 == 0 && data.ano % 100 != 0))
        {
            maxDiaMes = 29;
        }
        else
        {
            maxDiaMes = 28;
        }
        break;
    case 4:
    case 6:
    case 9:
    case 11:
        maxDiaMes = 30;
        break;
    default:
        maxDiaMes = 31;
    }
    printf(" Dia (%d a %d): ", 1, maxDiaMes);
    data.dia = lerInteiro(1, maxDiaMes);

    return data;
}

Variante 1Comparar duas datas

Elabore uma função que compare duas datas e devolva -1 se a primeira for anterior, 0 se forem iguais e 1 se for posterior.

Tenta escrever primeiro no Code::Blocks. Dica: Compara primeiro o ano, depois o mês, depois o dia. Serve para qualquer condição “desde/antes de uma data”.

/* Devolve -1 se d1 for anterior a d2, 0 se forem iguais, 1 se d1 for posterior */
int comparaDatas(tipoData d1, tipoData d2)
{
    int resultado = 0;

    if (d1.ano != d2.ano)
    {
        resultado = (d1.ano < d2.ano) ? -1 : 1;
    }
    else if (d1.mes != d2.mes)
    {
        resultado = (d1.mes < d2.mes) ? -1 : 1;
    }
    else if (d1.dia != d2.dia)
    {
        resultado = (d1.dia < d2.dia) ? -1 : 1;
    }
    return resultado;
}

void ordenaPorVencimento(tipoFuncionario vetor[MAX_FUNCIONARIOS], int quantFunc)
{
    int i, j;
    tipoFuncionario aux;

    for (i = 0; i < quantFunc - 1; i++)
    {
        for (j = 0; j < quantFunc - 1 - i; j++)
        {
            if (vetor[j].vencimento < vetor[j + 1].vencimento)
            {
                aux = vetor[j];
                vetor[j] = vetor[j + 1];
                vetor[j + 1] = aux;
            }
        }
    }
}

Dois pormenores diferentes da Ficha 6, ambos de propósito: o menu() só chama limpaBufferStdin() se o carácter lido não for já o Enter (senão, carregar só Enter ficava à espera de outra linha); e o leFicheiroBinario() confirma que a quantidade lida não passa de 50 antes de ler o vetor.

Erros que fazem perder mais pontos

  • Esquecer quantFunc = acrescentaFuncionario(...) (sem guardar o valor devolvido, o funcionário “desaparece”).
  • Ciclos até MAX_FUNCIONARIOS em vez de até quantFunc (mostra lixo).
  • conta * 100 / quant sem cast → percentagem inteira (33 em vez de 33.33).
  • “Superior a 1000” com >=; “desde novembro de 2020 inclusive” só com ano >= 2020 (conta janeiro a outubro de 2020).
  • scanf("%s") para nomes (corta no espaço) — usa lerString.
  • fopen com "w"/"r" no binário, ou ler pela ordem errada (primeiro a quantidade, depois o vetor).
  • Falta de protótipo ou de #include <string.h> / <ctype.h>.
  • Repetir código em vez de reutilizar funções (procura, mostraFuncionario).
